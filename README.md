 TaskTracker / Helpdesk Simples

Projeto prático desenvolvido para o Bootcamp II de Engenharia de Software. O objetivo desta entrega é a atividade pratica, saindo da teória para a parte pratica de um sistema funcional em Python e organizado dentro do GitHub.

  Funcionalidades da Aplicação:
- Cadastrar Chamados: Permite registrar um novo chamado informando o título, uma descrição opcional, a prioridade e a data limite.
- Validações e Regras de Negócio: 
  - O título é obrigatório e o sistema barra entradas vazias ou com espaços em branco.
  - A prioridade possui validação rígida e aceita apenas: *Alta*, *Média* ou *Baixa*.
  - O status é definido automaticamente como Pendente no momento do cadastro.
- Visualizar Chamados: Exibe uma listagem formatada e limpa no terminal com todas as informações dos chamados salvos.

  Tecnologias Utilizadas
- Python 3 (Lógica de programação e tratamento de dados)
- Git e GitHub (Versionamento e organização do repositório)
